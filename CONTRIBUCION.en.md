# How to Change The Hive Plan

There are no owners. This is not a request, it is a proposal.

## Steps to modify

1. **Fork this repository** (button "Fork" at the top right).
2. **Change what you want.**
   - Remove a principle.
   - Add a new one.
   - Reorder the text.
   - Translate it.
3. **You don't need permission.**
   - Nobody will argue with you.
   - Nobody will block you.
   - Your version is valid.

## If you want to propose it to the main version

If you think your change improves the "original" version, you can open an **Issue** or a **Pull Request**, but remember:
- There is no "official" version here.
- The main version is only the one you choose to look at.

## The only rule (the only one)

**If you change this, leave it open too.**
CC0 in, CC0 out.
Don't close the table behind you.

## Mandatory Question

Before proposing any change, ask yourself:
> **Are we removing a stone or leaving a name?**

If you are leaving a name, this is not for the Hive. It is for you. Keep it in your own repository.
